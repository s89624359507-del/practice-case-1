Практика: Кейс-задача №1
Описание проекта
Консольное приложение на Node.js, которое запрашивает у пользователя дату рождения и выводит информацию о дне недели, високосном годе и возрасте.
Технологии
- JavaScript
- Node.js
Как запустить
1. Убедись, что установлен [Node.js](https://nodejs.org/).
2. В терминале перейди в папку с проектом и выполни:
   ```bash
   node date.js
   ```
